# Card network logos

The Payment Instrument panel (`src/components/merchant/CardBrandLogo.tsx`) shows each card
network's own logo from this folder. Add the official, unmodified files:

- `visa.svg`
- `mastercard.svg`
- `discover.svg`
- `amex.svg`

Take them from each network's brand center and follow its usage rules (clear space, no recoloring
or redrawing). Until a file is here, the panel shows the brand name as plain text instead.
