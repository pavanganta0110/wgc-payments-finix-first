# Card network logos

The Payment Instrument panel (`src/components/merchant/CardBrandLogo.tsx`) shows each card
network's logo from this folder: `visa.svg`, `mastercard.svg`, `discover.svg`, `amex.svg`. For any
other brand, or if a file is missing, it shows the brand name as plain text.

The four files are the unmodified `flat-rounded` set from the open-source project
[aaronfagan/svg-credit-card-payment-icons](https://github.com/aaronfagan/svg-credit-card-payment-icons),
licensed under Apache 2.0 (see `LICENSE-svg-credit-card-payment-icons.txt`). The marks themselves are
trademarks of their owners: show them only to identify the card, and do not recolor or redraw them.
